# RunRebels

Plattform für virtuelle Laufchallenges — lauf, wo und wann du willst,
innerhalb eines festen Zeitraums. Erste Challenge: **Laufrausch**, die
Neujahrschallenge.

Rebellisch im Ton, seriös in der Auswertung: laut und hyped nach außen,
aber mit einem fairen, nachvollziehbaren System darunter.
